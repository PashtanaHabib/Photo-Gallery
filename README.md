# Photo Gallery

A simple JavaScript practice project built using HTML, CSS, and JavaScript.

This project showcases five famous historical places in Herat, Afghanistan. Users can click on thumbnail images to view the selected photo along with its title and description.

## Live Demo

[View Live Demo](https://pashtanahabib.github.io/Photo-Gallery/)

## Technologies Used

- HTML5
- CSS3
- JavaScript

## JavaScript Concepts Used

- **Arrays:** Storing multiple places and their information.
- **Objects:** Organizing each place's ID, name, description, and image source.
- **DOM Manipulation:** Selecting and updating HTML elements.
- **querySelectorAll():** Selecting all thumbnail images.
- **forEach():** Looping through the images.
- **addEventListener():** Handling click events on images.
- **innerText:** Updating image titles and descriptions.
- **setTimeout():** Removing animation classes after a short delay.
- **classList.add():** Adding animation classes.
- **classList.remove():** Removing animation classes.
- **Arrow Functions:** Using callback functions with `forEach()`.

## Features

- Interactive photo gallery
- Dynamic image selection
- Display image titles and descriptions
- Smooth image transition animations
- Famous historical places of Herat

## Project Purpose

This project was created for practicing JavaScript fundamentals, especially arrays, objects, DOM manipulation, event handling, loops, and CSS animations controlled by JavaScript.
